# Project Guidelines - eml_rename

## Development Language
- **Official Development Language**: English (`en`).
- All source code, identifiers, function/variable names, comments, and docstrings must be written in **English**.
- User-facing terminal messages in the source code must be written in English inside the gettext translation wrapper `_("...")`.
- Localized translations for other languages are maintained via gettext `.po` files in `eml_rename/locale/` (e.g., `es`, `fr`, `pt`, `ru`, `ro`, `zh_CN`, `hi`).
